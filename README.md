# helloWorld

A basic Java console application that prints **"Hello, World!"** to the standard output. This repository demonstrates the structure of a simple Java project and can be used as a starting point for learning Java and version control.

## Features
- Minimal Java setup with a `src` folder and package/class structure.
- Example of how to structure a Java project.
- Demonstrates how to compile and run a Java program from the command line.

## Getting Started

### Prerequisites
- Java Development Kit (JDK) 8 or higher.
- Git installed on your system.

### Installation

Clone this repository and navigate into it:

```bash
git clone https://github.com/cyldzn/helloWorld.git
cd helloWorld
```

Open the project in your favourite IDE (e.g., Eclipse or IntelliJ IDEA), or compile and run from the command line:

```bash
javac src/helloWorld/HelloWorld.java
java helloWorld.HelloWorld
```

You should see the following output:

```
Hello, World!
```
