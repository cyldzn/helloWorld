# Python Project Samples

This directory contains simple command-line projects suitable for Python beginners.

## Projects

1. **simple_calculator.py** - Basic arithmetic calculator supporting addition, subtraction, multiplication, and division.
2. **todo_list.py** - Task manager that saves tasks to a JSON file.
3. **number_guessing_game.py** - Guess a random number between 1 and 100.
4. **text_adventure_game.py** - Small interactive adventure game.
5. **csv_data_analyzer.py** - Reads a CSV file and computes the average of a numeric column.

Each script can be run with `python3`.
